This package contains the same tool in three versions, for
DaVinci Resolve (DCTL and DRFX) and for Premiere Pro (MOGRT):
same platforms, same measurements, same graphics. Pick the one that
fits the way you work (you can install more than one).

-------------------------------------------------------------------
1) DaVinci_DCTL
-------------------------------------------------------------------
   File: AnotherPerspective_SafeZones.dctl
   - Used in the COLOR page, on a node (or on an Adjustment Clip).
   - Requires DaVinci Resolve STUDIO.
   - Has every control: opacity of safe area and mockup, margin,
     border thickness, crop guides, centre cross.
   Instructions: DaVinci_DCTL\INSTALL.txt

-------------------------------------------------------------------
2) DaVinci_DRFX
-------------------------------------------------------------------
   File: AnotherPerspective_SafeZones_v4.2.drfx
   - A Fusion title: drag it into the timeline in the EDIT page,
     like any title, and adjust it in the Inspector.
   - Controls: Platform, Mode, Phone, Occasional elements.
   Instructions: DaVinci_DRFX\INSTALL.txt

-------------------------------------------------------------------
3) Premiere_MOGRT
-------------------------------------------------------------------
   File: AnotherPerspective_SafeZones_v4.2.mogrt
   - Motion Graphics Template for Adobe Premiere Pro: drag it into
     the timeline and adjust it in the Properties / Essential
     Graphics panel.
   - Controls: Platform, Mode, Phone, Occasional elements.
   Instructions: Premiere_MOGRT\INSTALL.txt

Note: inside the programs the controls still have Italian names
(Piattaforma = Platform, Modalita = Mode, Telefono = Phone,
Elementi occasionali = Occasional elements).

-------------------------------------------------------------------
!! In every case: turn the overlay off before rendering,
   otherwise it ends up in the exported video.

   - Controlli: Piattaforma, Modalita, Telefono, Elementi occasionali.
   Istruzioni: DaVinci_DRFX\INSTALL.txt

-------------------------------------------------------------------
3) Premiere_MOGRT
-------------------------------------------------------------------
